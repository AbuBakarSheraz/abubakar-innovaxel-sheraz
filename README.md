# Take-Home Assignment – URL Shortening Service

This repository contains the solution to the take-home assessment for the position of Associate Software Engineer at **Innovaxel**.

## 🌐 Task Summary

Build a RESTful API for a URL shortening service with the following core features:

- Create a short URL from a long URL
- Retrieve the original URL using a short code
- Update an existing short URL
- Delete an existing short URL
- Get statistics (access count, creation time, etc.)
